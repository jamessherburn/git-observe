# git-observe

Browse a branch's commits and open any of them on GitHub.

## Install

```sh
brew install fzf
cp git-observe.sh ~/.local/bin/git-observe
chmod +x ~/.local/bin/git-observe
```

`~/.local/bin` must be on your `PATH`.

## Use

Run `git observe` in any repo, pick a branch, then press Enter on a commit to open it on GitHub.
